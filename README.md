# 🎨 Open-Source 3D Asset Library for Blender (v3.3+)

Bienvenue dans cette bibliothèque de ressources 3D open-source ! Après plusieurs années de création sur Blender (depuis la version 3.3), j'ai accumulé un grand nombre d'assets. N'ayant plus le temps de me consacrer à la 3D aujourd'hui, j'ai décidé de partager l'intégralité de mon travail personnel avec la communauté, dans le pur esprit open-source de Blender.

Que vous soyez artiste, développeur de jeux ou étudiant, servez-vous !

---

## 🚀 Contenu de la bibliothèque

Ce dépôt est divisé en plusieurs catégories prêtes à être intégrées dans vos projets :

* 🧱 **Textures & Matériaux :** Banques de textures PBR prêtes pour l'Asset Browser (bois, métaux, briques, textures procédurales...).
* 📦 **Modèles 3D :** Objets et props modélisés, optimisés et texturés.
* 🎬 **Animations :** Rigging et cycles d'animations (boucles, mouvements de caméra, etc.).
* 🖼️ **Scènes Complètes :** Fichiers `.blend` de scènes entières avec éclairage et composition configurés, parfaits pour l'étude ou le rendu.

---

## 📦 Comment l'utiliser dans Blender

### 1. Pour les Textures et Modèles 3D (Asset Browser)
* Téléchargez le dépôt et extrayez-le.
* Dans Blender, allez dans `Edit > Preferences > File Paths`.
* Dans **Asset Libraries**, ajoutez le dossier de ce projet.
* Ouvrez l'**Asset Browser** dans votre espace de travail pour glisser-déposer les objets et matériaux.

### 2. Pour les Scènes et Animations
* Ouvrez directement les fichiers `.blend` présents dans les dossiers dédiés pour explorer les animations et les configurations de scènes.
* Vous pouvez aussi utiliser la fonction `File > Append` dans votre projet en cours pour importer spécifiquement une collection, une animation ou une caméra de ces scènes.
